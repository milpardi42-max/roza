# سیستم 8D تصاویر — FX8D (در حال حاضر غیرفعال)

**وضعیت: OFF** — پس از بازخورد کاربر، هر دو لایه به حالت پیش‌فرضِ خاموش برگردانده شد
و سایت دقیقاً مثل قبل رندر می‌شود. زیرساخت باقی است و هر زمان می‌توان opt-in فعالش کرد.

## لایهٔ ۱ · افکت لایو — `FXImg`
- `src/components/fx/FXImg.tsx` با پیش‌فرض `fx={false}` ⇒ خروجی دقیقاً `<img>` ساده است.
- فعال‌سازی نقطه‌ای برای آینده: `<FXImg fx depth={…} zoom={…} tilt={…} />`
- فعال‌سازی سراسری: تغییر پیش‌فرض `fx = false` به `fx = true` در `FXImg.tsx` (حالت لطیف توصیه می‌شود: tilt=6, zoom=1.04, depth=0.05)
- استایل: `src/styles/fx8d.css`

## لایهٔ ۲ · گرید دائمی فایل — `scripts/grade-8d.mjs`
- عکس‌های `public/assets/**` به نسخه‌های اورجینال از `assets-originals/` برگردانده شدند (بدون گرید).
- اجرای دستی در آینده: `npm run grade` (فقط عکس‌های جدید) · `npm run grade:force` (همه، از بکاپ)
- مانیفست: `scripts/.graded-manifest.json`
